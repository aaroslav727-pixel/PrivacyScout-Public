# Privacy Scout — iOS-приложение для оценки слежки и советов по приватности

SwiftUI, iOS 16+, без сторонних зависимостей, без сети.

## Как это работает

iOS не позволяет приложению видеть другие приложения или заглядывать в них.
Зато сама система ведёт журнал **«Отчёт о конфиденциальности приложений»**
(App Privacy Report, iOS 15.2+): кто обращался к камере, микрофону, геолокации,
фото, контактам и с какими доменами связывалось каждое приложение.

Privacy Scout:
1. импортирует этот файл (NDJSON) через «Файлы»;
2. сопоставляет домены со встроенной базой трекеров (`TrackerDatabase.swift`);
3. считает оценку риска 0–100 и показывает, **почему** (`Analyzer.swift`);
4. даёт рекомендации по каждому приложению и общий раздел советов по анонимности.

Есть кнопка «Демо-данные» (вымышленные приложения) — можно посмотреть интерфейс без файла.

## Как запустить

### Вариант А — XcodeGen (быстро)
```bash
brew install xcodegen
cd PrivacyScout
xcodegen generate
open PrivacyScout.xcodeproj
```
В Xcode: выберите свою команду в Signing & Capabilities и запускайте на симуляторе или iPhone.

### Вариант Б — вручную
1. Xcode → File → New → Project → iOS App (Interface: SwiftUI, Language: Swift), название `PrivacyScout`.
2. Удалите сгенерированные `ContentView.swift` и `<Name>App.swift`.
3. Перетащите в проект все `.swift` файлы из папки `PrivacyScout/PrivacyScout/` (включая `Views/`).
4. Минимальная версия iOS — 16.0.

## Как получить отчёт на iPhone
Настройки → Конфиденциальность и безопасность → «Отчёт о конфиденциальности приложений» →
включить запись → через несколько дней нажать «Сохранить активность приложений» →
сохранить в «Файлы» → импортировать в Privacy Scout.

## Структура
| Файл | Назначение |
|---|---|
| `ReportParser.swift` | разбор NDJSON из iOS (устойчив к лишним/неизвестным полям) |
| `TrackerDatabase.swift` | база известных трекерных доменов (неполная, дополняйте) |
| `Analyzer.swift` | оценка риска, выводы, рекомендации, названия приложений |
| `AppState.swift` | состояние, импорт файла в фоне |
| `DemoData.swift` | демо-набор |
| `Views/` | экраны: анализ, детали приложения, советы, о приложении |

## Ограничения
- Оценка — эвристика, а не доказательство слежки.
- Журнал iOS охватывает около 7 дней.
- База трекеров неполная; добавляйте домены в `TrackerDatabase.raw`.
- Формат файла iOS не документирован Apple; парсер написан по известной структуре
  (`type: access` и `type: networkActivity`). Если Apple изменит формат, правьте `ReportParser.swift`.
- Код не компилировался в среде, где он писался (там нет Swift/Xcode): при первой сборке
  возможны мелкие правки.
